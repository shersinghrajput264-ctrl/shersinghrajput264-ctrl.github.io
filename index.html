Frequently asked questions

Helpful answers about Smart PDF Toolkit.

Is Smart PDF Toolkit free?

Yes. The core tools are intended to be free to use. Advanced functionality may be added in future versions.

Do I need an account?

No account is required for the basic browser tools.

Are my files uploaded?

For tools that use browser-side processing, files are processed locally in your browser. Check the specific tool's instructions before processing sensitive information.

Can I use it on Android?

Yes. The website is responsive and designed for modern mobile browsers and desktop browsers.

Can I merge multiple PDFs?

Yes. Use Merge PDF to select multiple PDF files and create a combined document.

Can I convert images to PDF?

Yes. Image to PDF supports common image formats such as JPG and PNG in the browser.

Are there file-size limits?

Browser processing depends on your device memory and browser capabilities. Very large files may take longer or fail on low-memory devices.

Can people worldwide use the site?

The site is publicly accessible and can be used from supported countries and browsers, subject to local network restrictions and service availability.
